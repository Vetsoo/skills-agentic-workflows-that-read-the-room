## Recent updates worth watching

_Last reviewed: October 15, 2026._

- **GitHub Actions: workflow lockfiles (public preview)** — Pin the exact commits behind your workflow's actions and reusable workflows with `.github/workflows/actions.lock`, created via the `gh actions-lock` CLI extension, so a moved tag or branch can't silently change what runs. Dependabot keeps lockfile entries in sync. Source: GitHub Changelog, October 14, 2026 — [GitHub Actions workflow lockfiles in public preview](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview).
- **Secret scanning: Anthropic keys blocked by default** — New detectors for Anthropic, Cloudsmith, and Salesforce secrets; the Anthropic key types are now blocked by push protection by default. Source: GitHub Changelog, October 13, 2026 — [Secret scanning blocks Anthropic keys by default, adds Salesforce](https://github.blog/changelog/2026-10-13-secret-scanning-blocks-anthropic-keys-by-default-adds-salesforce).
- **Copilot: HydraFusion and HydraFusion Max (research preview)** — Orchestrates multiple models into one response; available in VS Code, the GitHub Copilot app, and Copilot CLI on paid plans with preview features enabled. Source: GitHub Changelog, October 14, 2026 — [HydraFusion updates and new Max option](https://github.blog/changelog/2026-10-14-hydrafusion-updates-and-new-max-option).
